# CLI Builder Skill Pack

These small skills divide CLI construction into distinct responsibilities.

## Default route

```text
cli-research -> cli-plan -> cli-route-governance -> cli-build -> cli-debug-verify -> cli-release
```

Use only the skill needed for the current work.

## DSP-style mapping

| This pack | Useful DSP-style capabilities |
| --- | --- |
| `cli-research` | research, investigate, supply-chain |
| `cli-plan` | plan, grill, design, readiness |
| `cli-route-governance` | security, secrets, permissions, network, execution-security |
| `cli-build` | build, known-errors |
| `cli-debug-verify` | debug, full-debug, verify, review, recovery |
| `cli-release` | release, closeout, document |

These skill files are intentionally generic. They do not encode private Signalproof authority levels, internal evidence locations, or private infrastructure.
