# CLI Research

## Procedure

1. Identify the intended runtime and operating systems.
2. Verify exact model/provider identifiers.
3. Verify current API or local-runtime interfaces.
4. Record third-party license and redistribution obligations.
5. Identify credential, network, storage, and execution boundaries.
6. Separate verified facts from assumptions.
7. Produce a short decision record for planning.

## Stop when

A required license, provider identity, model identity, or security boundary is unresolved.
